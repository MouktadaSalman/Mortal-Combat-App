## About 
This project required designing and developing both a Gaming Lobby Server and a WPF Client Application, ensuring seamless interaction between multiple players. I successfully implemented:

User Authentication & Management: Unique player logins, ensuring no duplicate usernames.

Lobby Room System: Creation, joining, and management of lobby rooms, allowing multiple players to interact.

Real-time Messaging: Message distribution within lobby rooms, along with private messaging features.

File Sharing System: Secure sharing of image and text files within the lobby.

Asynchronous & Multi-threaded Operations: Implemented a background thread-based 'pull' system for real-time updates, ensuring smooth reception of lobby messages, private messages, and file transfers.

User Interface Design: Designed a user-friendly WPF interface that includes login, room selection, messaging, file sharing, and logout functionalities.

Performance Optimization: Ensured efficient handling of multiple clients and maintained responsiveness through threading and asynchronous operations.

This project showcases my proficiency in .NET, WCF, multithreading, real-time data communication, and UI development. My expertise extends to designing scalable systems that enhance user experience while maintaining performance and reliability. Whether developing real-time applications, managing databases, or optimizing system interactions, I am dedicated to creating high-quality, functional software solutions tailored to specific needs.
